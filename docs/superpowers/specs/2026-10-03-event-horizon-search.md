# Event Horizon search integration

This specification supersedes the visual direction of the earlier everyday Orbit workspace. The user requested a black-hole event horizon, fine luminous threads, typed-word bubble chains, whole-query contextualization after a pause and full prior search capabilities integrated into the interface and backend. Development, upload, merge and publication were explicitly authorized in the conversation.

## Interaction

Initialize the GPU renderer first, with WebGL2 and accessible Canvas2D fallbacks. Keep a quiet, full-viewport scene and four edge menus. Structural HTML remains the accessible input and result layer. Feed query state, activity, word target geometry and selection into the renderer. This is an artistic metaphor, without a claim of physical accuracy.

Each typed word becomes an ordered bubble. After 650 ms without typing (and after IME composition), analyze the complete query locally. Show the subject and proposed properties/aspects/questions underneath, with provenance and reasons. Acceptance and removal are explicit. Preserve ambiguity and exclusions. Keep semantic budget/date/location constraints separate from literal Must/Prefer/Avoid filters. Never call web providers while typing.

## Search preservation

Keep the original 734-record browser projection, seven-project registry and fourteen lessons available on the public page. Rebuild only from existing public shards with verified bytes and original UOIDs. Do not alter historical exported source, include excluded files, publish browser memory or turn restricted private-origin material into corpus/graph/export data. Public-carrier generation and browser imports reject restricted-origin markers recursively.

Restore the Conscience64API contracts: simple and advanced search, get/all/stats, relations, traversal, microdata/HTML, I/R/P/O history, projects, project reflow, invariants and lessons. Keep BM25 ranking, local notes, permitted teachings/helpful history, aliases and bounded source-preference learning. User memory remains on device and is distinguished from public records.

Integrate Wikipedia, OpenAlex, Crossref, Internet Archive and GitHub with explicit provider selection, concurrent retrieval, bounded requests, cancellation, partial failures, deduplication and source provenance. Apply query refinements once. Keep fetched candidates available when constraints are removed. Counts refer to the returned window.

Also retain the separate 65-route catalogue and 248 country profiles. Country selection adds a keyword hint; it does not impose geographic filtering. Category-filtered routes remain explicit source links. The local backend additionally invokes the original route planner and Crossref/Europe PMC retrieval. Public Pages is static; it does not host Python or claim a connected model.
